# Nexaply Enterprises — website

Static single-page site for Nexaply Enterprises, a Kerala plywood trading house.

- `index.html` — the page
- `css/style.css` — styles (colour tokens at the top; light and dark themes)
- `js/main.js` — truckload estimator, copy buttons, enquiry form to WhatsApp
- `assets/` — logo mark, favicon, hero illustration

No build step. Hosted on GitHub Pages; see `notes.md` for what to replace before going live and where prices live.
